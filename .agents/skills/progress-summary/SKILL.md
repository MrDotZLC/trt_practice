# 进度总结文档

当需要生成可交接给新会话的进度文档时，按以下结构输出 Markdown：

## 必须包含的章节

1. 项目目标（一句话）
2. 当前架构与关键决策（含为什么这么选）
3. 已完成的部分（文件 / 模块级别）
4. 进行中 / 未完成的部分
5. 已知问题与坑（含 workaround）
6. 下一步计划
7. 重要的环境信息（TensorRT 版本、CUDA 版本、依赖库版本等）

## 输出要求

- 只保留决策和状态，不复述对话过程
- 涉及取舍的地方写清楚“为什么选 A 不选 B”
- 输出为 Markdown，可直接存为 docs/PROGRESS.md
