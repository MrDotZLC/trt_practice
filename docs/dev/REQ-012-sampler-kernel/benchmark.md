# Benchmark Report

> **性质**：改动后对照。**性能判据由基线实测给出**，且必须**同二进制 A/B**（两版编进同一二进制，
> 同轮正反交替），否则跨 session 的数字不可比。

## Environment

GPU: NVIDIA GeForce GTX 1660 Ti Mobile（`sm_75`，无 Tensor Core）
TensorRT: 10.15.1　CUDA: 12.6.85

## Workload

与 `benchmark_before.md` 同规格：词表 50257 / 128000，行数 1 / 8，FP32 与 FP16。

## Measurement

同轮交替（ABBA）＋报中位数与四分位；同二进制内两版对照；平台判别下限约 ±400~600 µs。

## Comparison

| Metric | Before | After | Change |
|---|---|---|---|
| Top-P 加速比（对冻结基线，4 种形状） | 1× | **13.0× / 18.9× / 13.4× / 15.0×** | **4/4 达标** |
| 同一 session 口径（50257 × 1） | 1× | **9.99×** | 与冻结基线的差（0.08%）已定位为收尾段串行重扫 |
| Top-K 快速路径 | 1× | **更慢**（0.108~0.156×） | **撤出生产路径**（正确性通过） |

## Analysis

- **Top-P 达标**：判据由基线给出、同二进制 A/B 判定，4/4 通过。
- **Top-K 快速路径未达标**：正确但更慢，根因是占用率（一行只有一个 warp）与共享内存冲突；
  按"不把未达标的实现留在产品路径"的原则**撤出**，代码保留待重做。
- **收尾段的进一步并行化**：实施后同二进制 A/B 判定**无显著差异** → 代码保留为永久对照入口，**不设判据**。
- **第一趟访存/MLP 的进一步优化**：净开销已接近"裸读一遍行"，**优化空间见底，不做**。

## Decision

**Keep**（Top-P 部分）；**Rollback**（Top-K 快速路径撤出生产路径）。
