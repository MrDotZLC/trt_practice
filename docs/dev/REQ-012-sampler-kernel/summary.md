# Project Summary

> **性质**：历史交付总结回填（2026-10-01）。来源：本目录 `future_iterations_development_plan.md` §10.9 / §10.10 / §10.11。

## Problem

Top-K / Top-P 每步对整行词表做降序排序，单词表下是固定开销（Top-P 相对贪心高两个数量级）；
低精度与大词表边界缺少覆盖。

## Solution

在**语义不变**前提下降低每步采样开销：Top-P 保留排序、把行内数学块内并行化；
Top-K 改"部分选择 + 只对候选排序"；补齐低精度与大词表覆盖。

## Architecture

```text
每行一个 block：strided 扫描（行 max/sum）→ 寄存器候选 + 阈值迭代 → 块内归并 top-M
              → 只对候选排序 → 采样数学（与现状逐条一致）
```

## Implementation

先测基线 → 新 kernel → 语义回归用例 → 覆盖补齐 → 同二进制 A/B 性能判定 → 文档回填。

## Performance

| 项 | 结果 |
|---|---|
| Top-P（对冻结基线的 4 种形状） | **13.0 / 18.9 / 13.4 / 15.0 ×（4/4 达标）** |
| Top-K 快速路径 | 正确但**慢 6~9 倍** → **撤出生产路径** |
| 收尾段并行化 | 同二进制 A/B 判**无显著差异** → 保留代码、不设判据 |

## Limitation

- **Top-K 快速路径未达标**（占用率与共享内存冲突），已撤出、待重做。
- 第一趟访存的进一步优化**不做**：净开销已接近裸读一遍行。
- 采样器的**分布级参考数据未固化**（开放项）。
