## P0 Blockers

**"代码/文件已存在"不能作为通过依据**。初版判据让动态 shape 能力在"只声明未实现"的状态下也算通过，
该缺口直到 Phase 1.5 才补齐。此后所有阶段的判据一律写成可执行形式——这是本项目沿用至今的纪律。

## P1 Risks

- 第三方依赖若以动态库形式接入，换机器与分发都会受制于宿主环境 → 一律源码嵌入或静态构建。
- 张量文件解析的边界（缺文件、坏格式、缺张量）必须在测试里显式覆盖，否则后面每个模型都会踩。

## P2 Quality

目录分层与命名统一，便于后续按模块扩展。

## Decision

**PASS**（判据改为可执行后）。
