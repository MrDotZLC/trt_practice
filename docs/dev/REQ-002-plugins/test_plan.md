# Test Plan

> **性质**：历史用例回填（2026-10-01）。来源：`docs/dev/REQ-002-plugins/phase1_test_plan.md` §1/§2/§4
> 与 `docs/dev/REQ-003-test-infra/phase1_5_test_plan.md` §2（执行结果）。**判据以 `requirement.md` 为准**。

## Unit Test

每个算子有其自身的算子级单测（构造输入、与 CPU 参考对比、覆盖边界与非法参数），
与"经真实使用路径调用"的端到端用例分工不同（见下）。

## Integration Test

**E1 单算子最小模型闭环（4 条，真机）**——验证算子能通过**真实使用路径**被调用：
权重从权重文件取出、经名字映射挂成常量，而不是测试里手工构造权重。

| 用例 | 算子 | 关键验证点 |
|---|---|---|
| E1.1 | 归一化 | 权重经名字映射命中；`eps` 与隐藏维经引擎往返仍正确 |
| E1.2 | 旋转位置编码 | 位置编码作为网络输入传入；**部分旋转时尾部保持原值** |
| E1.3 | 分页注意力 | 块表 / 上下文长度作为输入；跨多个物理块的寻址正确 |
| E1.4 | 采样器 | 引擎输出 logits 直接进采样器（不经主机往返）；固定种子可复现 |

> E1.4 的采样器不是插件，因此它验证的是"引擎输出 → 采样器 → token"这段衔接。

## Regression Test

- 每个 Plugin 的算子级单测在沙箱 / 真机均可运行（GPU 用例在无设备时显式跳过）。
- 插件序列化往返：克隆、序列化字段往返、反序列化后按形状刷新配置。

## Failure Test

- 非法参数（负数头数 / 非法块大小 / 越界索引）必须显式失败而非静默。
- 索引类输入类型错误（非 32 位整型）必须被拒绝。
- 半连接的输入（只给键不给值）必须被拒绝。

## Expected Result

四个交付物各有单元测试；全部 GPU 用例在真机通过。

## Actual Result

沙箱内 GPU 用例显式跳过；真机验证通过。后续阶段补齐了算子级的端到端覆盖（见 `REQ-003-test-infra`）。
