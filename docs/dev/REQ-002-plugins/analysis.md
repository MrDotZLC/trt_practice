# Analysis

> **性质**：历史分析回填（2026-10-01）。来源：本目录 `phase1_development_plan.md` §1~§5。

## Current Architecture

骨架已就绪（构建、基础设施、引擎封装、注册表），但**没有任何算子**：归一化、位置编码、注意力、
采样这四类推理必需的算子都缺失；插件接口也只有空壳基类。

## Data Flow

算子要通过**真实调用路径**被使用，而不是测试里手工挂载：

```text
config.json + 权重 → 构建入口 → 构建器 → 挂插件 → 网络 → 引擎 → 推理
                    ↑ 插件创建器注册在这里
```

## Relevant Modules

| 模块 | 开工时状态 |
|---|---|
| 插件基类 | 空壳，缺公共序列化与命名空间样板 |
| 归一化 / 位置编码 / 分页注意力 | 不存在 |
| 采样器 kernel | 不存在 |
| 创建器与注册 | 不存在 |

## Existing Limitations

1. 没有算子，任何真实模型都建不出来。
2. 插件接口版本仍是旧版思路，需按当前接口（能力拆分）重写。
3. 动态形状与显存工作区两条项目硬约束，必须在算子层就落实。

## Extension Points

- **插件基类**：一次写好，后续每个算子只实现业务接口。
- **创建器注册**：是"外部图路径"与"原生路径"共用算子的前提。
- **采样器 kernel**：后续所有采样策略（Top-K / Top-P / 后续扩展）都从这里接。
