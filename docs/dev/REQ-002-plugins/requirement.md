## Problem

框架需要一组"自己写"的推理算子：Transformer 推理的热点算子在通用运行时里要么没有、
要么在目标架构上不够用；同时动态形状与显存分配必须符合项目硬约束。

## Goal

交付第一批量产算子与它们的插件封装：统一的插件基类封装、三个推理算子插件、
采样器的 CUDA 实现，并保证每个算子都有单元测试。

## Scope

### Included

1. 完善插件基类封装，适配当前 TensorRT 版本的插件接口。
2. 实现归一化插件。
3. 实现旋转位置编码插件。
4. 实现基础版分页注意力插件——**仅解码阶段**，支持 MQA/GQA/MHA。
5. 实现采样器 kernel（贪心 / Top-K / Top-P）。
6. 每个插件与 kernel 都要有单元测试。

**产出物**：插件类 + 创建器 + 注册逻辑；对应 CUDA kernel 实现；单元测试；进度文档更新。

### Excluded

- 分页注意力的**预填充阶段**（查询序列长度 > 1）——与解码路径结构差异大，另行处理。
- 采样器的分布级正确性对比（当时只做了词频统计检验与参考脚本打印，数据固化留后）。

## Acceptance Criteria

来源：`docs/dev/REQ-002-plugins/phase1_development_plan.md` §1 产出物 + `docs/dev/REQ-002-plugins/phase1_test_plan.md`。

1. 插件基类封装完成，能按当前接口版本正确实例化、序列化与反序列化。
2. 三个插件各自通过单元测试；分页注意力覆盖 MQA/GQA/MHA 与多块情形。
3. 采样器三个策略各通过单元测试（含边界：空上下文、越界参数、并发列）。
4. 全部 GPU 用例在真机验证通过（沙箱无 GPU 只能跳过，不构成验证）。

## Constraints

- 必须使用当前版本的插件接口能力拆分方式，不使用旧版动态插件接口。
- 显式支持动态形状。
- 动态暂存显存必须通过运行时的 workspace 机制申请，**不在执行期临时分配**。
- 目标架构固定、单卡；精度与显存受目标机限制。
