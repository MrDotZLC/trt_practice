# Project Summary

> **性质**：历史交付总结回填（2026-10-01）。来源：本目录 `phase1_development_plan.md` §5 / §6。

## Problem

骨架已就绪但没有任何算子，真实模型建不出来；插件接口还是旧版思路，且动态形状与显存工作区两条
项目硬约束尚未在算子层落实。

## Solution

补齐插件基类封装，实现三类算子插件与采样器 kernel，并为每个算子配单元测试。

## Architecture

```text
插件基类（样板 + 命名空间）
   ├─ 归一化插件
   ├─ 位置编码插件（支持部分旋转）
   └─ 分页注意力插件（仅解码阶段，MQA/GQA/MHA）
采样器 kernel（贪心 / Top-K / Top-P）—— 自由函数，不走插件
创建器 + 注册逻辑
```

## Implementation

四个交付物 + 各自单元测试；算子通过"测试专用构建器 + 真实权重加载路径"被调用，而不是手工挂载。

## Performance

**不适用**（性能优化明确延后，见 `benchmark_before.md`）。

## Limitation

- **分页注意力只做解码阶段**：预填充用原生算子拼图。
- **采样器只保证正确性**：整行排序，性能优化另立项。
- **算子的使用者问题**：当时唯一的目标模型用不上归一化与位置编码插件，其价值要等接入相应模型族才兑现。
