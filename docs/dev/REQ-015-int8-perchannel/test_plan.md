# Test Plan

> **性质**：历史用例回填（2026-10-01）。来源：`docs/future_iterations_development_plan.md` §13.6 与
> `docs/future_iterations_test_plan.md` §3。**判据以 `requirement.md` 为准**。

## Unit Test

- **仪器自证（B1-1）**：探针读数落在量化格点上。
- **确定性（B1-2）**：同一张探针图两次运行读数一致。
- 标尺自证：用最小量化图**逐位**比对到手算语义（不靠"应该一样"这句话）。

## Integration Test

- **逐层曲线（B1-3）**：探针图下逐层对比"逐张量 vs 逐通道"两臂。
- **现象复现（B1-4）**：探针图下**逐通道仍然更差**（硬门）。

## Regression Test

- 默认路径与正式产物**逐字节未变**（本条目不动生产代码与默认产物）。
- 既有低精度用例不出现新红。

## Failure Test

两条硬约束：**仪器不过不取数**（自证或确定性任一不过 → 本轮作废，先修仪器）；
**现象不复现不解释**（复现门不过 → 结论只能是"探针改变了现象"，不许拿别的曲线去解释原来的退化）。

## Expected Result

定位到分叉层并给出机制，且该机制能被更小的复现解释。

## Actual Result

达成：根因是**量化尺度取自另一份张量**（尺度来源与量化对象不一致），
而非后端问题；该结论**推翻了两条旧结论**，并派生出两条通用纪律。

## Status

已结案（历史条目）。
