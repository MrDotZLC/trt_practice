# Analysis

> **性质**：历史分析回填（2026-10-01）。来源：本目录 `future_iterations_development_plan.md` §13.1 / §13.3。

## Current Architecture

逐通道权重量化在**整网**上比逐张量差得多，但在**最小可复现的算子级对照**上两者没有差异
（甚至逐通道更好）。此前已排除多条假设，原因仍未找到——这是"现象明确、机制未知"的悬案，
且它直接决定低精度路线的粒度选择。

## Data Flow

```text
数值标尺（官方参考实现直接执行量化图）
        ↓ 与引擎逐层对比
    探针图（= 产物图 + 只追加输出，其余逐字节不变）
        ↓
    逐层分叉定位 → 机制解释 → 离线反证（直接读文件里的量化常量）
```

## Relevant Modules

| 模块 | 开工时状态 |
|---|---|
| 数值标尺 | 需要一把**独立**且**自身可信**的尺子 |
| 探针 | 需要能看"量化前"的张量 |
| 逐层对比 | 需要可复核的分层读数 |
| 产物 | 正式产物与复现样本混在一起，身份不清 |

## Existing Limitations

1. 现象在整网上成立、在最小图上不成立 → 必须逐层定位。
2. 探针自身可能改变现象（挂图影响后端融合）。
3. 此前用"量化后"的张量做探针 → 分辨率被量化台阶淹没。

## Extension Points

- **独立标尺**：官方参考实现直接执行量化图 → **从源头消掉"折叠"这一步**。
- **量化前张量探针**：把信噪比从"整格噪声"提到"浮点差异"。
- **文件级证据**：直接读图里的量化常量，不依赖任何后端行为。
