# Project Summary

> **性质**：历史交付总结回填（2026-10-01）。来源：本目录 `future_iterations_development_plan.md` §13.2 / §13.6。

## Problem

逐通道权重量化在**整网**上明显比逐张量差，但在**最小算子级对照**上两者无差异——现象明确、机制未知，
且此前已排除多条假设。

## Solution

按"仪器先行"的顺序做：先证明探针可信（格点 + 确定性），再证明现象在探针图下复现，
然后逐层定位，最后用**离线文件级证据**反证——二选一的目标里选了"定位根因并解释机制"。

## Architecture

```text
独立标尺（官方参考实现直接执行量化图，从源头消掉"折叠"这一步）
        ↓ 逐层对比
    探针图（只追加输出、其余逐字节不变）
        ↓
    逐层分叉定位 → 机制解释 → 直接读图里的量化常量做离线反证
```

## Implementation

六条设计决策 → 探针图生成（含"只追加输出"的断言）→ 逐层读数 → 两臂对照 →
离线反证（不依赖后端行为）→ 真机确认。

## Performance

**不适用**（本条目是数值根因定位，不做性能）。

## Limitation

- 结论**只针对本模型与本产图脚本**：机制是"尺度来源与量化对象不一致"，不是通用结论。
- 两件后续事项（把脚本默认尺度源切到另一路、重生成逐通道产物）**按决定暂不做**
  （触发条件 = 带真值标签的验收集到位）。
