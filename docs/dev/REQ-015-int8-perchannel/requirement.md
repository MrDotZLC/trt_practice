## Problem

逐通道权重量化在整网上比逐张量差得多，但在最小可复现的算子级对照上两者**没有差异**
（甚至逐通道更好）。此前已排除多条假设，原因仍未找到——这是一个"现象明确、机制未知"的悬案，
且它直接影响低精度路线的粒度选择。

## Goal

**二选一，不接受"下次再看"**：

1. 定位到**从第几层开始分叉**并说明机制（该机制还要能被算子级 / 块级最小复现解释）；或
2. 证明所有可查方向均已查空，逐条写明"为什么这条路不能再查"。

## Scope

### Included

- 仪器先行：探针图的可信度（探针值必须落在量化格点上、同一图两次运行确定性一致）。
- 现象复现：在探针图下仍能观察到"逐通道更差"。
- 逐层定位与机制解释。
- 离线反证（不依赖后端行为）。

### Excluded

- 不借机改量化工具链的默认行为（默认产物必须逐字节可复现）。
- 不做语言模型侧的量化和 KV 缓存量化。
- 不重生成任何既有产物（那会让既有用例变红，且它不是缺陷）。

## Acceptance Criteria

来源：`docs/future_iterations_development_plan.md` §13.6（两条硬约束）+ §13.2 的"二选一"。

1. **仪器不过不取数**：探针自证（格点）与确定性检查任一不过 → 本轮作废，先修仪器。
2. **现象不复现不解释**：探针图下若不再更差 → 结论只能是"探针改变了现象"，
   不许拿别的曲线去解释原来的退化。
3. 达成 Goal 的二选一之一（最终为前者：定位到根因与机制）。

## Constraints

- 探针要探**量化前**的浮点张量，不探量化后——量化台阶会把正常差异在桶边界放大成整格噪声。
- 标尺必须独立于被测实现，且自己先被校准。
- 能离线验的别上真机；先找"不依赖后端行为的证据"。

## 历史演进（抽取时保留）

- 本条目的结论**推翻了两条旧结论**：此前认为"现象成因在后端"的推断是错的，
  真正原因在产图脚本的尺度来源（量化对象与尺度来源不一致）。
- 由此派生出两条**通用纪律**，已写入项目纪律：① 量化尺度必须取自被量化那张张量本身；
   ② 标尺必须独立于被测实现且自带校准。
