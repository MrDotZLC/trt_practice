# Benchmark Report

> **不适用（性能）**：本条目没有性能目标。它的"对照"是**数值对照**：逐通道 vs 逐张量，
> 在探针图上按层比较。

## Environment

GPU: NVIDIA GeForce GTX 1660 Ti Mobile（`sm_75`，无 Tensor Core）
TensorRT: 10.15.1　CUDA: 12.6.85

## Workload

同一批输入，两臂：逐通道量化图 / 逐张量量化图；逐层读"量化前"的张量。

## Measurement

逐层读数 + 格点占比自证 + 噪声地板当场量出（不预设绝对阈值）。

## Comparison

| 项 | 结果 |
|---|---|
| 仪器自证（格点占比） | ✅ 通过（探到的确实是量化前张量） |
| 确定性（同图两次运行） | ✅ 一致 |
| 现象复现（探针图下仍"逐通道更差"） | ✅ 复现（PT 全对 / PC 明显更差） |
| 文件级证据 | **坏值已烘进文件**：逐通道的 int8 权重被 clamp 饱和比例显著更高（与后端无关） |
| 根因 | **尺度来源与量化对象不一致**：尺度取自未折归一化的权重，而量化对象是已折的权重 |

## Analysis

- **决策不变**：默认产物仍是逐张量，**不改默认行为**（逐字节可复现）。
- **两条旧结论被推翻**：此前"现象成因在后端"的推断是错的；错在产图脚本。
- **派生两条通用纪律**：① 量化尺度必须取自被量化那张张量本身；② 标尺必须独立且自带校准。

## Decision

不适用（无性能可 Keep / Rollback）；**默认行为保持不动**。
