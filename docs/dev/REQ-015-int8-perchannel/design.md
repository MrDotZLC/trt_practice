# Design

> **性质**：历史设计回填（2026-10-01）。从 `docs/future_iterations_development_plan.md` §13.3 设计决策抽取，
> **未新增当时的决定**。

## Overview

定位"逐通道权重比逐张量差"的根因，或证明所有可查方向已查空。**二选一，不接受"下次再看"**。

## Architecture

```text
数值标尺（独立第三方参考实现）
        ↓ 与 TRT 引擎逐层对比
    探针图（= 产物图 + 只追加输出，其余逐字节不变）
        ↓
    逐层分叉点定位 → 机制解释 → 离线反证（读文件里的量化常量）
```

## Module Design

| 决策 | 内容 | 为什么 |
|---|---|---|
| **D1 标尺 = 官方参考实现** | 直接执行那份量化图，**不用"自己折 BN 的 torch 模型"** | 图里 BN 已折进卷积 → **不存在"折叠"这一步可错**；且它是完全独立的第三方实现 |
| **D2 探"量化前"的张量** | 不探量化后 | 量化台阶会把正常差异在桶边界放大成整格噪声，噪声与信号同量级 |
| **D3 用格点占比自证"探到的是量化前"** | 不靠"再折一遍" | 自证要能独立成立 |
| **D4 噪声地板当场量出** | 由对照臂实测，不预设绝对阈值 | 预设阈值等于拍脑袋 |
| **D5 探针清单** | 20 个卷积原始输出 + 全局池化输出 + 契约输出 | 覆盖"分叉在哪一层"的必要分辨率 |
| **D6 必须验证"探针图下退化仍复现"** | 否则本轮结论无效 | 挂图会改变后端融合 → 现象可能被探针本身改变 |

## Data Structure

```text
探针读数 = { 层名, 与标尺的差值, 格点占比 }
判据：d_pre ≤ d_post（量化前差值应小于量化后差值）
```

## Runtime Flow

```text
① 仪器自证（格点 + 确定性）→ 不过就作废、先修仪器
   ↓
② 现象复现（探针图下仍"逐通道更差"）→ 不复现只能写"探针改变了现象"
   ↓
③ 逐层定位 → 机制解释
   ↓
④ 离线反证（读文件里的量化常量，与后端行为无关）
```

## Resource Lifecycle

- 探针图是**新产物**，与产物图并存；断言"只追加输出、其余逐字节不变"。
- 不重生成任何既有产物（那会让既有用例变红，且它不是缺陷）。

## Performance Consideration

不涉及性能。

## Trade-off

| 决策 | 选择 | 为什么 |
|---|---|---|
| 探针挂在哪些层 | 全卷积 + 池化 + 契约输出 | 逐层分辨率不足时，会得出"NaN 层在漂移"这类被观测缺口误导的结论 |
| 是否顺手改工具链默认行为 | **不改** | 默认产物必须逐字节可复现 |
