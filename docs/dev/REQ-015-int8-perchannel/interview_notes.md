# Interview Notes

> **性质**：历史面试口径回填（2026-10-01）。这是本项目**最有代表性的一次根因定位**。

## Project Introduction

"一个'看起来像后端的锅'的精度问题：逐通道量化在整网上比逐张量差，但在最小图上两者一样。
最后的结论是——**产图脚本量错了对象**：量化尺度取自未折归一化的权重，而量化对象是已折的权重。"

## Architecture Explanation

三层证据：① **仪器可信**（探针落在量化格点上、两次运行确定性一致）；② **现象复现**
（探针图下仍逐通道更差）；③ **文件级证据**（直接读图里的 int8 常量，数被 clamp 饱和的比例——
与后端无关）。此外标尺用**官方参考实现**直接执行量化图，从源头消掉"折叠"这一步。

## Key Decisions

| 决策 | 选择 | 理由 |
|---|---|---|
| 标尺用什么 | **官方参考实现**直接执行量化图 | 用"自己折归一化的模型"会引入同类错误 |
| 探针探什么 | **量化前**的浮点张量 | 量化后的值被台阶噪声淹没，分辨率不够 |
| 噪声地板 | **当场量出** | 预设绝对阈值等于拍脑袋 |
| 现象不复现怎么办 | 结论只能是"探针改变了现象" | 不许拿别的曲线解释原来的退化 |
| 默认产物 | **不动** | 默认行为必须逐字节可复现 |

## Technical Challenges

1. **探针本身会改变现象**（挂图影响后端融合）→ 必须验证"现象仍复现"。
2. **"量化后"的探针分辨率不够**：量化台阶会把正常浮点差异放大成整格噪声。
3. **历史上被观测缺口误导过**：中途一度以为"出问题的层在漂移"，实际是探针只覆盖了第一层。

## Trade-offs

- 坚持逐层定位（多花真机往返）→ 换来**机制级**结论，而不是"换个配置碰巧好了"。
- 不改默认产物 → 换来可复现，代价是逐通道路线暂不可用。

## Interview Questions

### Level 1

Q：这条在查什么？　A：逐通道量化为什么在整网上更差。

### Level 2

Q：结论是什么？　A：产图脚本的尺度来源与量化对象不一致（量错了对象）。

### Level 3

Q：怎么排除"是后端的问题"？　A：用独立标尺 + 逐层探针 + 文件级证据（坏值已烘进文件，与后端无关）。

### Level 4

Q：探针为什么必须探"量化前"？　A：量化后的值被台阶噪声主导，分辨不出真正差异。

### Level 5

Q：这次沉淀了什么通用纪律？　A：① 量化尺度必须取自被量化那张张量本身；② 标尺必须独立且自带校准。

## Follow-up Questions

- 还有什么没做？（切换默认尺度源、重生成逐通道产物——等带标签的验收集到位）
