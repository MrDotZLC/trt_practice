# Test Plan

> **性质**：历史用例回填（2026-10-01）。来源：`docs/future_iterations_development_plan.md` §12.6。
> **判据以 `requirement.md` 为准**。

## Unit Test

分片纯函数的边界：无重叠无遗漏、不整除时的切法确定、空片、只有当前 token、
目标片长边界、片数上限钳位、工作区覆盖最大偏移、分解数学自洽。
**护栏自证**：把"余数摊给前几片"临时改坏，对应用例当场转红，复原后全绿。

## Integration Test

算子级数值：MHA / GQA / MQA、批量 > 1、跨多块、上下文长度为 0、带当前 token、
总长小于片数（空片）——每项都有用例，对 CPU 双精度参考满足既有算子口径。

## Regression Test

- 语义不变（硬）：解码一致性用例通过；8 token 贪心输出与既有基线**逐 token 一致**。
- 缓存安全：版本号 bump 后第一次全部重建、第二次命中缓存。

## Failure Test

工作区不足 / 形状非法 → 显式失败；不放松任何数值判据。

## Expected Result

长上下文档的每步**斜率**相对基线至少降 40%；短上下文档的退化作为观测项、不设判据。

## Actual Result

达成（斜率降幅约 88%）；三角证据：算子级 A/B、端到端 A/B、新旧实现诊断差值
（差值量级 = 浮点累加顺序不同）。
