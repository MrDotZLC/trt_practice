# Benchmark Report

> **性质**：改动后对照。两个层级各自独立出数，且**互校**（kernel 级 × 层数 ≈ 端到端）。

## Environment

GPU: NVIDIA GeForce GTX 1660 Ti Mobile（`sm_75`，无 Tensor Core）
TensorRT: 10.15.1　CUDA: 12.6.85

## Workload

与 `benchmark_before.md` 同规格（同 session、同引擎、逐轮 ABBA）。

## Measurement

同二进制 A/B（旧单趟 kernel 永久保留作对照）+ 同轮交替 + 报中位数与四分位 + 打印自身漂移锚点。

## Comparison

| 层级 | Before（单趟） | After（分片） | Change |
|---|---|---|---|
| kernel 级（每层每步，ctx=1024） | 0.918948 ms | **0.125568 ms** | **7.318×** |
| kernel 级（ctx=256） | 0.174143 ms | 0.094844 ms | 1.836× |
| kernel 级（ctx=32） | 0.023600 ms | 0.025764 ms | 0.916×（多一次归并，小回归） |
| **kernel 级斜率** | 0.902569 ms/1000 | **0.100609 ms/1000** | **−88.853%** |
| **端到端（prompt=960 每步）** | 13.0443 ms | **3.9932 ms** | **3.267×** |
| **端到端斜率** | 10.795 ms/1000 | **1.2738 ms/1000** | **−88.20%**（两次独立复现 88.12 / 88.20） |

**互校**：kernel 级 ctx=1024 的 0.918948 × 12 层 ≈ 11.03 ms/步；端到端斜率 10.795 × 0.976 ≈ 10.5 ms/步
→ 两把独立尺子差约 5%，一致。

## Analysis

- **性能达标**：判据是"ctx≈960 档每步 decode 斜率至少降 40%"（工程取定），实测降约 **88%**。
- **短上下文（ctx≈32）小回归 0.916×**：来自多一次归并发射（每层 1 次 × 12 层）。按作者决定，
  这一档**作为观测项、不设判据**——"不超过同 session 漂移"这个说法因"漂移"定义有歧义而作废。
- **数值**：新旧两版对同一输入的差值 `max_abs = 3.57628e-07`、`max_rel = 1.52484e-06`，
  比算子判据低约 65 倍——就是 float32 累加顺序不同的量级；**没有放宽任何阈值**。
- **缓存安全**：图版本与插件版本同批 bump，第一次全部重建、第二次命中（属预期）。

## Decision

**Keep**（分片路径为生产路径；旧单趟实现永久保留作 A/B 对照与兜底）。
