## Summary

评审推翻了一个**来自设计文档的预设**：原计划写"替换三类子图"，但实测该图**不含**其中两类
（没有旋转位置编码、没有归一化插件，用的是原生归一化 + 学习式位置编码）。评审据此把范围收窄。

## Checklist Result

| Item | Level | Result | Action |
|---|---|---|---|
| 子图替换范围 | P0 | 本模型上"替换"**无正确性收益**，性能收益未量化 | 先只做识别 + 断言（决策 D1=C） |
| 对齐判据 | P0 | 沿用上一阶段实测口径，**不预先放宽** | 若偏差更大按实测报告再定 |
| 外部图是否支持解码 | P1 | 该图是整段前向、无 past 输入 | 支持解码要重新导出 → 本阶段**不做** |
| profile 与精度 | P2 | 复用既有能力 | 参照历史工程校验一遍 |

## P0 Blockers

**"按设计文档做替换"会做错方向**——可替换对象在本模型上要么收益为零（原生层已足够），
要么用不上（分页注意力只做解码，而该图没有 K/V 输入）。这条被当场记录并改变了方案。

## P1 Risks

| 风险 | 影响 | 应对 |
|---|---|---|
| 图结构变化导致既有结论失效 | 静默错误 | 探针进 ctest，缺环境跳过、缺资产判红 |
| 单点性能测量被当成结论 | 方向性误判 | 明确记为"未定"，交后续可复现协议 |

## P2 Quality

外部图与原生路径共用同一份 I/O 契约常量。

## Decision

**PASS**（范围按实测收窄为"识别 + 断言"，性能结论记为未定）。
