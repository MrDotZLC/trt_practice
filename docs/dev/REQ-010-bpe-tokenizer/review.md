# Review Report

> **性质**：历史评审回填（2026-10-01）。来源：本目录 `future_iterations_development_plan.md` §2.1 与 §0.5 决策项。

## Summary

评审定了三件事：数据文件放哪、载入接口怎么承载两个文件、参考数据怎么固化。另有一处**实现期
发现的偏差**（用例层级从真机改到 host）被记录在案。

## Checklist Result

| Item | 决定 | 理由 |
|---|---|---|
| 数据文件放哪 | **不入库**，由环境/构建变量指向；缺文件跳过并打印探测结果 | 与"大产物不入库"一致 |
| 载入接口 | **不改基类**：入参解释为目录 | 不动已交付接口，避免扩散 |
| 参考数据 | **golden 入库**（含文本 + ids + 生成环境 + 来源校验） | 体积小，它是标尺 |
| 用例层级 | 文本入口的等价性判据**放 host** | 该链路只有一个变量（分词）；真机数值部分已被既有用例覆盖 |
| 公共解析器 | 实现期追加 `\uXXXX` 支持（计划里没写） | 词表 key 全是转义形式，不补就读不进来 |

## P0 Blockers

无遗留；唯一的"前置障碍"（解析器不支持转义）在实现期被发现并补上，且**补了覆盖**。

## P1 Risks

| 风险 | 影响 | 缓解 |
|---|---|---|
| 词表/合并规则缺文件 | 用例无法跑 | 显式跳过并打印探测结果（不静默） |
| 实现与参考不一致 | 分词错但不报错 | 与独立参考**逐 token 全等**（不是"接近"） |
| 参考数据被改 | 标尺失真 | golden 带来源字段与哈希，另有自证用例 |

## P2 Quality

公共组件的改动必须带覆盖（"改公共件必须有覆盖"是本项目的既有要求）。

## Decision

**PASS**（含一处实现期偏差：用例层级真机 → host，已在测试计划登记）。
