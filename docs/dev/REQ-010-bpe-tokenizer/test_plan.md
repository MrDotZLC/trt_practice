# Test Plan

> **性质**：历史用例回填（2026-10-01）。来源：`docs/future_iterations_test_plan.md` §2.1。
> **判据以 `requirement.md` 为准**（与独立参考**逐 token 全等**）。

## Unit Test

| 用例 | 判据 |
|---|---|
| 从目录装载 | 返回 true，词表规模 = 50257 |
| 拒绝缺失 / 畸形输入 | 目录不存在 / 缺合并规则 / 坏 JSON / 行格式错 → 返回 false（**不抛异常、不静默降级**） |
| 基础样本编码 | 与 golden 逐 token 全等 |
| 空白样本编码 | 同上；含**前导空格 / 连续空格 / 换行 / 制表符**——这是最易错处（实现期两次踩坑） |
| 多语言样本编码 | 同上；中文 / emoji / 中英混排 / 重音拉丁 / 日文 / 西里尔 / 全角 / CJK 标点 / ZWJ / 货币符号 |
| 长文本编码 | 同上；样本 ≥256 token，覆盖多次归并的深路径 |
| 解码 | 对 golden 的 ids 解码与参考全等；并确认参考自身可逆 |
| 边界 | 空串 → 空 ids；空 ids → 空串 |
| **参考自证** | 来源字段齐全、离线标志为真、词表规模正确、每个 id 落在词表内、样本结构完整 |
| 文本入口等价 | `Encode(文本)` 逐 token 等于既有用例里的基线常量 |

## Integration Test

参考数据的**可复现性**由独立 ctest 项承担：重新用参考实现算一遍再比对。

## Regression Test

公共 JSON 解析器的转义支持（6 条）——单转义、代理对、孤立代理、非法十六进制、ASCII 不回归。

## Failure Test

畸形输入必须返回失败而非异常或降级（同上表第 2 条）。

## Expected Result

14 条用例（含 6 条解析器用例）全绿；与独立参考逐 token 全等。

## Actual Result

全部通过。**计划与实现的一致性经核对**：列出的用例名 10/10 一致；
解析器那 6 条属实现期追加。
