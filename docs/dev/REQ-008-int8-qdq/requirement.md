## Problem

低精度量化有两条路线：隐式校准（需要 Calibrator）与显式量化节点（Q/DQ）。前者在当前
运行时版本已废弃并指向强类型方向；后者需要自己产出量化图并保证精度可判。
另外，低精度的"合格线"不能照搬浮点精度那一套。

## Goal

以**对称** Q/DQ 显式量化产出外部图，复用既有外部图路径完成端到端推理；
同时把"低精度怎么算合格"写成有出处的判据。

## Scope

### Included

- 量化产图路线（主线：在框架内产图；备选：外部量化库；再备选：原生插 Q/DQ）。
- 权重与激活的量化形态（对称性、粒度）。
- 判据与阈值纪律。
- 产物形态决策（预量化常量 vs 量化-反量化对）。

### Excluded

- 隐式校准路线（已废弃，冻结备查）。
- 强类型网络的整体改造（仅当"弱类型下 Q/DQ 不被尊重"被证实时才启动，且**必须先停下汇报**）。

## Acceptance Criteria

来源：`docs/dev/REQ-008-int8-qdq/phase4_int8_plan.md` §4 判据表（逐条状态如下）。

1. ~~分布外输入（合成 ramp）逐样本 argmax 一致~~ **已作废**——该口径对低精度不成立：
   输入与标定分布不同必然饱和。这是"判据的有效性依赖被测量对象的机制"的实例。
2. **真实图输入的 top-1 一致率**：按**率**判，不用"全一致"；阈值必须由更大样本实测给出，
   并写清"为什么这个率可接受"。
3. **权重图形态 = 预量化常量**：与"量化-反量化对"数值等价，但体积显著更小；已采纳。
4. **数值上界**：当时不作判据——样本分布外、绝对差被少数样本放大；主判据用一致率。
5. **不许跨精度复用阈值**。
6. **不达标时只允许三选一**：继续查 / 证明期望值本身错并给独立依据 / 标"已知失败 + 原因未知"
   保持红色。**禁止**调阈值换绿。
7. **量化尺度必须取自被量化那张张量本身**（交付期间补充的硬约束）。

## Constraints

- 采样样本要足够多：标定集本身分布退化，样本少时"率"的判别力很弱。
- 量化对象与尺度来源必须一致——这是本条交付期间踩到的根因（详见 `PROGRESS.md` 的量化纪律节）。
- 产物身份要钉死：正式产物与"复现样本"是两回事，不能混用。
