# Test Plan

> **性质**：历史用例回填（2026-10-01）。来源：`docs/dev/REQ-007-resnet18/phase4_test_plan.md` §1 分层 / §3 判据。

## Unit Test

**L0 host 契约（沙箱）**：配置解析、**转换产物的权重名与形状**、前处理的纯函数。
放最前是因为它们是后面所有数值结论的地基。

## Integration Test

| 层 | 测什么 | 环境 |
|---|---|---|
| L1 建网 | 两条路径的 I/O 契约（名字 / 形状 / 动态轴）、层数与关键形状冒烟、缺权重必须失败 | 真机 |
| L2 数值 | 各路径 vs 外部基线；原生 vs 外部图互拍；低精度两档 | 真机 |
| L3 端到端 | 运行时推理（批量 1/8/16）、超范围拒绝、基准可跑 | 真机 |
| L4 性能（可选） | 批量扫描的中位数与极差 | 真机 |

## Regression Test

逐样本 argmax 一致与数值阈值**并列**，不互相替代。

## Failure Test

- 批量超范围（0 / 超出上限）必须显式失败。
- 缺少权重文件 / 形状不符 / 构造失败必须显式失败，不得静默。

## Expected Result

四层全绿；两条路径与外部基线三方一致。

## Actual Result

达成。**低精度判据的演进**（口径曾被整体替换）见 `docs/dev/REQ-008-int8-qdq/test_plan.md`。

## Status

已交付（历史条目）。

## 输入与基线（原 PH4-TEST-INPUTS）

| 输入集 | 来源 | 用途 |
|---|---|---|
| 合成 ramp | 与历史工程同式（`(i % 255) / 255`），**不归一化** | **引擎级**对拍；不依赖任何图像文件 |
| 真实像素质 | 由校准集前 8 张**反归一化**回 `[0,255]` 的 float32 | **运行时**对拍与前处理公式交叉验证；运行时的输入契约就是它 |

> **两套输入的归一化状态不同，不能混用**：ramp 未归一化，像素质需要消费方按 ImageNet
> mean/std 归一化。混淆会得到"引擎错了"的假象。

已产出的基线产物：两套输入各一份参考输出与元数据（含权重与产物的 SHA256、逐样本 argmax）、
契约输入张量，以及像素质**归一化后**的张量（供前处理公式对拍）。
